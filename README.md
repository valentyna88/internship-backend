# Internship-backend

Backend service on NestJS.

## Requirements

- Node.js (LTS)
- npm

## Install

```bash
npm install
```

## Compile and run the project

```bash
# development
npm run start
```

```bash
# watch mode
npm run start:dev
```

By default app runs on http://localhost:3000

## Run tests

```bash
# unit tests
npm run test
```

```bash
# e2e tests
npm run test:e2e
```

## Environment variables

Create a `.env` file in the project root.

- `PORT` — port where the HTTP server will run (default: 3000)

Example:

```env
PORT=3000
```
